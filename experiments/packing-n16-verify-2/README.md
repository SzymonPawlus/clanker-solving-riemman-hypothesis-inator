# `packing-n16-verify-2` — independent checkers for $n=16$ covering certificates

Verification pass 2. Write-up:
[`problems/circle-packing-equilateral-triangle/attacks/n16-verification-2/`](../../problems/circle-packing-equilateral-triangle/attacks/n16-verification-2/README.md).

**Written from the problem statement only.** These do not read, import or adapt
`../packing-n16-covering/certify.py` (the author's certifier) or
`../packing-n16-verify/manager_covering_check.py` (the previous pass). The only thing consumed
from another worker's tree is certificate **data**.

Python standard library only (`fractions`, `json`, `itertools`, `math`). **No float in any
decision** — `math` appears only in `area_ceiling.py`, which is a commentary on someone else's
non-rigorous ceiling and asserts nothing.

## Scripts

| script | what it does |
|---|---|
| `covercheck.py [cert.json ...]` | The checker. Nine exact checks: piece count, simple-strict-convexity, containment in $T_a$, **strict** max squared diameter over all vertex pairs, agreement with the reported value, all $\binom k2$ pairs interior-disjoint by exact convex clipping, exact area identity, grid probe for holes, grid probe for double interiors. Plus five self-tests. Defaults to the standing certificate. |
| `adversarial.py` | Eight families of break attempts on the standing certificate: corners, per-edge 2001-point probes, $\varepsilon$-neighbourhoods of all 31 piece vertices, second/third-largest diameters, per-piece maxima, union area by a second route, de-duplicated count, and the dilate-to-the-ceiling control. |
| `negative_controls.py` | Ten corruptions of the **real** certificate, each of which must be rejected — including diameter exactly 1 (the Lemma L failure mode) and overlap-plus-equal-area-hole (the area-only argument's blind spot). Writes them to `controls/`. |
| `scale_up.py` | The certificate's max diameter is exactly $49999/50000$, so it has unused margin. Emits five dilated certificates into `scaled/`, runs each through `covercheck.py` in full, and states the supremum $a_{16}\ge 446335/99998$. |
| `area_ceiling.py` | D1: reproduces `KILL-CRITERION.md` K4's ceiling $4.5603$ and shows its per-piece area cap $3\sqrt3/8$ is false (the disk of diameter 1 has area $\pi/4$). The rigorous replacement, $a\le5.0392$, is vacuous. |

## Conventions (fixed by the problem's `RULES.md` §2)

Triangular basis $e_1=(1,0)$, $e_2=(1/2,\sqrt3/2)$; $|ue_1+ve_2|^2 = u^2+uv+v^2$ is **rational**;
$T_a=\{u\ge0,\ v\ge0,\ u+v\le a\}$. Separation normalised to 1, so $s = 2a+2\sqrt3$. The $(u,v)$
chart is linear with determinant $\sqrt3/2$, so `area(X) == area(Y)` may be tested with plain
$(u,v)$ shoelace areas and no irrational ever appears.

## Certificate shape accepted

```json
{ "a": ["num", "den"],
  "faces_uv": [ [ ["num/den", "num/den"], ... ], ... ],
  "max_sq_diam": "num/den"     // optional; recomputed and compared, never trusted
}
```

Exact rationals only — decimal strings are refused (`RULES.md` §2). Pieces must be simple,
strictly convex polygons; a curved piece is refused, because the "diameter is attained at a vertex
pair" step is a statement about polygons.

## Run

```bash
python3 covercheck.py
python3 adversarial.py
python3 negative_controls.py
python3 scale_up.py
python3 area_ceiling.py
```

No seeds, no tolerances, no network. Every script exits non-zero on any failure. Total ~1 min.
`controls/` and `scaled/` are regenerated by their scripts.
