certificate except where an exact q_min is printed, and no optimality is claimed anywhere.

5. THE MARGIN CURVE AND THE COUNTEREXAMPLE WINDOW

   Elementary: deleting a point gives m(n) <= m(n-1). Hence any counterexample to EO(k)
   has  1/(k-1) < m(Delta(k)-1) <= m(Delta(k)-2), so its triangle side lies in

        a  in  [ 1/m(Delta(k)-2),  k-1 ).

   delta(k) := m(Delta(k)-2) - 1/(k-1) is therefore an upper bound on how badly EO(k) can
   fail. m(Delta(k)-2) is not known exactly for any k >= 3, so the table substitutes the
   published best-known d(Delta(k)-2); the window is CONDITIONAL on that record being
   optimal, and is `numerical`. For k >= 9 no published value exists (GL stops at n=36) and
   the entry is this project's own best-found value -- a LOWER bound on m(Delta(k)-2), so
   the window shown there is a lower bound on the true window's width, not the window.
