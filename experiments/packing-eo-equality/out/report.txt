5. Theorem D: equilateral hull, no interior points -- the arithmetic
==============================================================================
Equality gives n = (a^2+3a+2)/2 ; boundary-only gives n <= 3*floor(a).
Hence a^2 + 3a + 2 <= 6*floor(a) <= 6a, i.e. a^2 - 3a + 2 <= 0, i.e.
1 <= a <= 2.  Roots of a^2-3a+2 are exactly 1 and 2:
  a=1: True    a=2: True
Sub-case a in [1,2): floor(a)=1 so n <= 3, and n = (a^2+3a+2)/2 >= 3
  with equality at a=1 only (a^2+3a-4 = (a+4)(a-1)):
    a=1: n_eq=(a^2+3a+2)/2=3  bound 3*floor(a)=3 -> feasible: True
    a=3/2: n_eq=(a^2+3a+2)/2=35/8  bound 3*floor(a)=3 -> feasible: False
    a=19/10: n_eq=(a^2+3a+2)/2=1131/200  bound 3*floor(a)=3 -> feasible: False
Sub-case a=2: n = 6 = 3*floor(2), so the boundary bound is tight, so
  every side carries exactly 3 points at spacing exactly 1.
A grid check that no other a in [1,3] can satisfy both constraints:
  integer-n solutions of the joint constraint on a 1/100 grid in [1,3]: [(Fraction(1, 1), Fraction(3, 1)), (Fraction(2, 1), Fraction(6, 1))]
