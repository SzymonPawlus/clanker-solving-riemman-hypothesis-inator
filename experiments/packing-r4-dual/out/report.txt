STEP 3 -- the collapse proposition, its checkable half
==============================================================================
PROPOSITION (attack README section 2).  The 'free score' LP -- one
independent variable per face shape and per boundary-edge length --
has the SAME optimal value as the two-variable reduced LP.

Proof (prose, `sketch`; written out in the attack README section 2):
  (i)  (D) caps each variable pointwise by the LINEAR member's value
       sigmahat(s) = c_A area(s) - 1/2,  tauhat(l) = c_L l - 1/2.
  (ii) (V) is a sum of the variables with coefficient +1, hence
       MONOTONE NONDECREASING in each of them.  So replacing any
       feasible (sigma, tau) by its cap (sigmahat, tauhat) preserves
       (V), and keeps (D) (with equality).  The objective involves
       only (c_A, c_L), which are untouched.
  (iii)Therefore the two LPs have the same feasible projection onto
       (c_A, c_L), hence the same optimal value, and the linear member
       is always among the optimal solutions.
  (iv) At the cap, (V) on a configuration K reads
         c_A A_K - F_K/2 + c_L M_K - b_K/2 >= 0,
       because sum_f area(f) = A_K exactly (the faces tile conv E).
       Euler F = 2n - b - 2 gives (F_K + b_K)/2 = n_K - 1, so this is
         c_A A_K + c_L M_K >= n_K - 1,
       EXACTLY the reduced LP's constraint.  QED

The checkable half is step (iv)'s arithmetic: (F+b)/2 = n-1 on every

  What this does and does not settle.  Steps (i)-(iv) close: the
  measured 'max |sigma - linear| = 0.00e+00' is FORCED, in the sense
  that the linear member is always AN optimal solution and the optimal
  VALUE is unchanged by freeing sigma pointwise.  What is NOT proved,
  and was not claimed, is that every optimal solution has sigma at its
  cap: when (V) is slack the LP has other optima, and the solver's
  choice of vertex is not determined by this argument.

  The deeper reading (`sketch`).  (D) + (V) are used ONLY through
  their consequence  c_A A_K + c_L M_K >= n_K - 1.  Even the strictly
  larger family that replaces pointwise (D) by its summed form

  the SHAPE OF THE CONCLUSION.  Any bound of the form
      n <= 1 + c_A*area(conv E) + c_L*perimeter(conv E)
  is pinned by the lattices and rhombi, on which it is tight, and
  those pin it to Oler at every a.  Improving on Oler requires a
  conclusion that is NOT affine in (area, perimeter).
