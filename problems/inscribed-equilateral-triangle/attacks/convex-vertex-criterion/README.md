## 1. Setting and notation

`K ⊂ R²` is compact and convex with nonempty interior; `J = ∂K`. Identify `R² = C`.

For `O ∈ J` let

  Γ(O) = { λ(x − O) : x ∈ K, λ ≥ 0 },   T(O) = closure of Γ(O)

be the cone generated by `K − O` and its closure, the **tangent cone**. Define `α(O)` as the
opening of `T(O)`; F2 below says this is well defined and lies in `(0, π]`.

Throughout a proof about a fixed `O` we **normalise**: translate so `O = 0` and rotate so that

  T(O) = { r e^{iθ} : r ≥ 0, θ ∈ [0, α] },  α = α(O).

Write, for this normalisation,

  A   = { arg z : z ∈ K \ {0} } ⊆ [0, α]        (the *achieved* directions)
  r(θ) = max { t ≥ 0 : t e^{iθ} ∈ K }           for θ ∈ [0, α]   (the radial function from O)
  Σ(θ) = { t > 0 : t e^{iθ} ∈ J }               (the boundary radii in direction θ)

`r` is well defined (`K` compact, `0 ∈ K`) and `r(θ) > 0` ⟺ `θ ∈ A`.

**Definition.** `O ∈ J` is a **good vertex** if there are `P, Q ∈ J` with `{O,P,Q}` the vertex
set of a nondegenerate equilateral triangle.

`ρ` denotes rotation by `−π/3` about `O`, i.e. `ρ(z) = e^{−iπ/3} z` after normalisation.

### Elementary facts, proved

**F1 (cone containment).** `K ⊆ O + T(O)`.
*Proof.* For `x ∈ K`, `x − O = 1·(x − O) ∈ Γ(O)`. ∎

This is the entire geometric content of the obstruction, and it is *immediate from the
definition of `T(O)` as the closure of the cone generated by `K − O`*. The brief warned that this
step is where an error would hide. It is not — but only because of the definition chosen. If one
instead defines the tangent cone by limits of secant directions, or by tangent lines, the
containment becomes a theorem needing convexity, and for a **non**-convex curve it is simply
false. Convexity is doing its work twice here: it makes `Γ(O)` convex (hence an angular sector
with a well-defined opening), and it makes the containment trivial.

**F2 (`α ∈ (0, π]`).** `Γ(O)` is a convex cone (cone generated by the convex set `K − O ∋ 0`).
Since `O ∈ ∂K` there is a supporting line at `O`, so `K − O` and hence `Γ(O)` and `T(O)` lie in a
closed half-plane through `0`; a closed convex cone in a half-plane is an angular sector of
opening `≤ π`. Since `K` has nonempty interior, `Γ(O)` contains the directions from `O` to a ball
inside `K`, so the opening is `> 0`. ∎

**F3 (`A` is an interval with the right endpoints).** `A` is convex: `Γ(O)` is a convex cone
inside a half-plane, so its nonzero arguments form an interval. `inf A = 0`: otherwise
`Γ(O) ⊆ {arg ∈ [a, α]}` for some `a > 0`, a closed set, so `T(O)` would too, contradicting
`T(O) = {arg ∈ [0,α]}`. Similarly `sup A = α`. Hence

  (0, α) ⊆ A ⊆ [0, α],   and in particular  r(θ) > 0 for all θ ∈ (0, α).  ∎

**F4 (radial interior lemma).** If `θ ∈ (0, α)` and `0 < t < r(θ)` then `t e^{iθ} ∈ int K`.
Consequently `Σ(θ) = { r(θ) }` for every `θ ∈ (0, α)`.
*Proof.* By F3 pick `ψ₁ < θ < ψ₂` in `A` with `ψ₂ − ψ₁ < π`, and `x₁, x₂ ∈ K\{0}` at those
arguments. The triangle `conv{0, x₁, x₂}` is nondegenerate, is contained in `K`, and equals
`{ s e^{iφ} : φ ∈ [ψ₁,ψ₂], 0 ≤ s ≤ ℓ(φ) }` for a continuous positive `ℓ`; its interior contains
`δ e^{iθ}` for all `0 < δ < ℓ(θ)`. Fix such a `δ < r(θ)`; then `w := δ e^{iθ} ∈ int K`. With
`y := r(θ) e^{iθ} ∈ K`, the standard convexity fact "`w ∈ int K`, `y ∈ K` ⟹ `[w, y) ⊆ int K`"
gives `t e^{iθ} ∈ int K` for `δ ≤ t < r(θ)`, and `t < δ` is already covered. For the consequence:
`r(θ) e^{iθ} ∈ J` because points beyond it on the ray are outside `K`. ∎

**F5 (extreme rays are boundary).** If `0 ∈ A` then `Σ(0) = (0, r(0)]`; likewise at `α`.
*Proof.* If `t e^{i·0} ∈ int K` for some `t > 0`, a ball around it inside `K` contains points of
argument `< 0`, contradicting `K ⊆ T(O) = {arg ∈ [0,α]}` (F1). So the whole segment is in `J`. ∎

**F6 (semicontinuity).** `r` is upper semicontinuous on `[0, α]` and continuous on `(0, α)`.
*Proof.* usc: if `θₙ → θ*` and `r(θₙ) → c` (bounded, `K` compact) then `r(θₙ)e^{iθₙ} → c e^{iθ*}`,
which lies in the closed set `K`, so `c ≤ r(θ*)`. Lower semicontinuity on `(0,α)`: if
`θₙ → θ* ∈ (0,α)` and `r(θₙ) → c < r(θ*)`, pick `c < t < r(θ*)`; by F4 `t e^{iθ*} ∈ int K`, which
is open, so `t e^{iθₙ} ∈ K` for large `n`, i.e. `r(θₙ) ≥ t > c` — contradiction. ∎

Note F6 says nothing about `r` at `θ = 0` or `θ = α`, and `r` genuinely can be discontinuous
there (see §4.1). That gap is exactly where (C2) fails.

### The reduction that makes everything computable

**Proposition R.** `O` is a good vertex **iff** there exists `θ` with `θ ∈ [0,α]`,
`θ − π/3 ∈ [0,α]`, and `Σ(θ) ∩ Σ(θ − π/3) ≠ ∅`.

*Proof.* (⇐) Take `t` in the intersection and set `P = t e^{iθ}`, `Q = t e^{i(θ−π/3)}`. Both lie
on `J`, both differ from `O`, `|OP| = |OQ| = t > 0`, and `∠POQ = π/3` (the two arguments lie in
`[0,α] ⊆ [0,π]` so their unsigned angle is their difference). An isoceles triangle with apex
angle `π/3` is equilateral, and it is nondegenerate because `t > 0`.
(⇒) If `O,P,Q ∈ J` form a nondegenerate equilateral triangle then `|OP| = |OQ| =: t > 0` and
`∠POQ = π/3`; writing `P = t e^{iθ_P}`, `Q = t e^{iθ_Q}` with `θ_P, θ_Q ∈ A ⊆ [0,α]` (F1) and
`|θ_P − θ_Q| = π/3`, relabel so `θ_P = θ_Q + π/3` and take `θ = θ_P`. ∎

By F4/F5, `Σ(θ) = {r(θ)}` when `θ ∈ (0,α)`, and `Σ(θ) = (0, r(θ)]` when `θ ∈ {0, α} ∩ A`.
**This distinction is load-bearing and it is what I initially got wrong** (§4.2).

## 2. The four statements

### Theorem A (= C1, obstruction) — `sketch`

> Let `O ∈ J` with `α(O) < π/3`. Then `O` is not a good vertex.

*Proof.* Stronger form first: **if `P, Q ∈ K \ {O}` then `∠POQ ≤ α(O)`.** Indeed `P − O` and
`Q − O` lie in `T(O)` (F1), an angular sector of opening `α(O) ≤ π` (F2); writing their arguments
as `θ_P, θ_Q ∈ [0, α]` their unsigned angle is `|θ_P − θ_Q| ≤ α ≤ π`. Now if `O,P,Q` were a
nondegenerate equilateral triangle with all vertices on `J ⊆ K`, then `∠POQ = π/3 ≤ α(O)`. ∎

Note this uses only convexity and `O ∈ ∂K`; not compactness, not nonempty interior beyond
making `α` well defined.

### Theorem B (= corrected C2, existence) — `sketch`   **[ATTACK HERE]**

> Let `O ∈ J`.
> **(i)** If `α(O) > π/3` then `O` is a good vertex.
> **(ii)** If `α(O) = π/3` then `O` is a good vertex **iff** `A = [0, π/3]`, i.e. iff *both*
> extreme rays of the tangent cone `T(O)` meet `K` in a segment of positive length.
> **(iii)** If `α(O) < π/3` then `O` is not a good vertex (Theorem A).
>
> In particular, if the extreme rays of `T(O)` meet `K` in nondegenerate segments — which holds
> at every point of a convex **polygon**, and more generally whenever `A` is closed — then
> `O` is good ⟺ `α(O) ≥ π/3`, which is (C2) exactly as briefed.

*Proof of (ii).* With `α = π/3` the only admissible pair in Proposition R is `θ = π/3`,
`θ − π/3 = 0`. If `A = [0,π/3]` then `Σ(π/3) = (0, r(π/3)]` and `Σ(0) = (0, r(0)]` (F5), both
nonempty, and they intersect (any `t ≤ min(r(0), r(π/3))`). If `A ≠ [0,π/3]` then `0 ∉ A` or
`π/3 ∉ A`, so one of `Σ(0), Σ(π/3)` is empty and Proposition R fails. ∎

*Proof of (i).* Assume `α > π/3`, so `(π/3, α)` is a nonempty open interval and, by F3,
`π/3` and `α − π/3` both lie in `(0, α)` with `r(π/3) > 0`, `r(α − π/3) > 0`.

*Case A: `r(0) ≥ r(π/3)`.* Then `r(0) > 0`, so `0 ∈ A`. Put `t = r(π/3)`. Then
`t ∈ Σ(π/3)` by F4, and `t ≤ r(0)` gives `t ∈ Σ(0)` by F5. Proposition R applies.

*Case B: `r(α) ≥ r(α − π/3)`.* Then `r(α) > 0`, so `α ∈ A`. Put `t = r(α − π/3)`. Then
`t ∈ Σ(α − π/3)` by F4, and `t ≤ r(α)` gives `t ∈ Σ(α)` by F5. Proposition R applies.

*Case C: `r(0) < r(π/3)` and `r(α) < r(α − π/3)`.* Define, on `(π/3, α)`,

  F(θ) = r(θ) − r(θ − π/3).

Both arguments lie in `(0, α)` there, so `F` is continuous by F6. Its endpoint behaviour:

- `liminf_{θ→π/3⁺} F ≥ r(π/3) − limsup_{ψ→0⁺} r(ψ) ≥ r(π/3) − r(0) > 0` — the middle step is
  continuity of `r` at `π/3 ∈ (0,α)` together with **upper** semicontinuity at `0`. So there is
  `θ₁ ∈ (π/3, α)` with `F(θ₁) > 0`.
- `limsup_{θ→α⁻} F ≤ limsup_{θ→α⁻} r(θ) − r(α − π/3) ≤ r(α) − r(α − π/3) < 0` — upper
  semicontinuity at `α`, continuity at `α − π/3 ∈ (0,α)`. So there is `θ₂ ∈ (π/3, α)` with
  `F(θ₂) < 0`.

By the intermediate value theorem there is `θ₀` strictly between `θ₁` and `θ₂`, hence in
`(π/3, α)`, with `F(θ₀) = 0`. Then `θ₀ ∈ (0,α)` and `θ₀ − π/3 ∈ (0, α − π/3) ⊆ (0,α)`, so by F4
`Σ(θ₀) = {r(θ₀)}` and `Σ(θ₀ − π/3) = {r(θ₀ − π/3)} = {r(θ₀)}`. Proposition R applies. ∎

Cases A, B, C are exhaustive (C is the negation of A ∨ B).

**Degeneracy is ruled out explicitly, not by picture.** In every case the produced radius is
`t > 0`: in Case A, `t = r(π/3) > 0` by F3 since `π/3 ∈ (0,α)`; in Case B, `t = r(α−π/3) > 0`
likewise; in Case C, `t = r(θ₀) > 0` since `θ₀ ∈ (0,α)`. The classical failure mode of this
subject — the solution collapsing to `P = Q = O` — is exactly the statement `t = 0`, and it is
excluded because `r` is strictly positive on the *open* angular interval `(0,α)`, which is where
all three cases put the witness.

### Theorem C (= C3, counting; strengthened) — `sketch`

> **(a)** At most two points of `J` have `α(O) < π/3`.
> **(b)** At most three points of `J` have `α(O) ≤ π/3`; if there are exactly three, they are the
> vertices of an equilateral triangle, `K` *is* that triangle, and all three are good vertices.

*Proof.* Recall the strong form of Theorem A: `P, Q ∈ K \ {O}` ⟹ `∠POQ ≤ α(O)`.

(a) Suppose `O₁, O₂, O₃ ∈ J` are distinct with `α(Oᵢ) < π/3`. They are not collinear: if `O₂`
were between `O₁` and `O₃`, then `∠O₁O₂O₃ = π > α(O₂)`, contradicting the strong form. So they
form a nondegenerate triangle whose angle at `Oᵢ` is `∠OⱼOᵢO_k ≤ α(Oᵢ) < π/3`; the three angles
sum to `π` but are each `< π/3`, so their sum is `< π`. Contradiction.

(b) The same argument with `≤ π/3` forces every triple among such points to be an equilateral
triangle. Four such points `O₁,…,O₄` are impossible: `O₁O₂O₃` and `O₁O₂O₄` equilateral on the
common base `O₁O₂` force `O₄` to be the reflection of `O₃` in the line `O₁O₂`, whence
`|O₃O₄| = √3·|O₁O₂| ≠ |O₁O₃|`, contradicting `O₁O₃O₄` equilateral. If there are exactly three,
say `O₁,O₂,O₃`, they form an equilateral triangle `T`; at each `Oᵢ` the two directions towards
the others subtend exactly `π/3 ≤ α(Oᵢ) ≤ π/3`, so `α(Oᵢ) = π/3` and `T(Oᵢ)` is exactly the cone
those two directions span. Hence `K ⊆ ⋂ᵢ (Oᵢ + T(Oᵢ)) = T` by F1, and `T ⊆ K` by convexity, so
`K = T`. Each vertex is then good, witnessed by `T` itself. ∎

**This replaces the total-turning argument in the brief and is strictly better**: it needs no
notion of total curvature for a general convex curve, no rectifiability, and no restriction to
polygons. The only external ingredient is that the angles of a Euclidean triangle sum to `π`.

### Proposition D (= C4, sharpness) — `sketch` (with an exactly verified witness)

> Let `K` be the closed triangle with vertices `O = (0,0)`, `B = (1,0)`, `C = (−1/2, √3/2)`.
> Its angles are `120°` at `O` and `30°` at `B` and `C`. Then:
> - `B` and `C` have `α = π/6 < π/3` and are **not** good vertices (Theorem A);
> - every other point of `J` is a good vertex: interior points of the three edges have `α = π`,
>   and `O` has `α = 2π/3`, all `> π/3` (Theorem B(i));
> - so `J` has **exactly two** non-good points, attaining the bound in Theorem C(a) and in
>   Corollary E.

An explicit inscribed equilateral triangle with a vertex at the `120°` corner (verified in exact
arithmetic, see §5):

  O = (0, 0),  P = (0, 1/√3),  Q = (1/2, 1/(2√3)),  side = √3/3.

`P` and `Q` both lie on the edge `BC`, at parameters `2/3` and `1/3` from `B`; all three pairwise
distances equal `√3/3` exactly. This corresponds to Case **A** of Theorem B, not Case C — `r(0) = 1 ≥ r(π/3) = 1/2`, so
Case A fires and Case C is by definition its negation. (Correction from `AUDIT.md` item 4;
Case A's own witness is `(0,0), (1/2,0), (1/4,√3/4)`, side `1/2`.) Formerly stated as Case C with `θ₀ = π/2`
(measuring from the edge `OB`), since `r(π/2) = r(π/6) = 1/√3` by the reflection symmetry of the
isoceles triangle about its axis `θ = π/3`.

A **second**, structurally different, witness for the bound 2 is the body `K*` of §4.1: its two
non-good points are `(0,0)` (with `α = π/3` exactly, failing by the *new* mechanism) and
`(1, √3)` (with `α = π/6`, failing by Theorem A).

### Corollary E — `sketch`

> Let `K ⊂ R²` be compact convex with nonempty interior and `J = ∂K`. Then all but at most two
> points of `J` are good vertices; in particular `J` inscribes a nondegenerate equilateral
> triangle.

*Proof.* By Theorems A and B, `O` non-good ⟹ `α(O) ≤ π/3`. By Theorem C(b) there are at most
three points with `α ≤ π/3`; if there are exactly three then `K` is an equilateral triangle and
all three are good, so there are **no** non-good points; otherwise there are at most two points
with `α ≤ π/3`, hence at most two non-good points. Since `K` has nonempty interior, `J` is
uncountable, so good vertices exist. ∎

## 3. Regularity budget

Exactly which hypotheses each statement consumes. "Convex" always means `K` convex.

| Statement | `K` convex | `O ∈ ∂K` | `K` compact | `int K ≠ ∅` | other |
|---|---|---|---|---|---|
| F1 containment | yes | no (any `O ∈ K`) | no | no | — |
| F2 `α ∈ (0,π]` | yes | yes (supporting line) | no | yes (for `α > 0`) | — |
| F3 `A` interval | yes | yes | no | yes | — |
| F4 radial interior | yes | yes | no (only `r(θ)` finite) | yes | — |
| F5 extreme rays | yes | yes | no | yes | uses F1 |
| F6 semicontinuity | yes | yes | **yes** (usc needs `K` closed + bounded) | yes | — |
| **Thm A (C1)** | yes | yes | no | for `α` to be defined | — |
| **Thm B (C2′)** | yes | yes | **yes** | yes | IVT on `R` |
| **Thm C (C3)** | yes | yes (all three points) | no | for `α` to be defined | angle sum `= π` |
| **Prop D (C4)** | — | — | — | — | exact arithmetic |
| **Cor E** | yes | — | yes | yes | `J` uncountable |

Explicitly **not** consumed anywhere: smoothness or `C¹`-ness; rectifiability or finite length;
the Jordan curve theorem; that `∂K ≅ S¹`; any degree, winding-number or parity argument; any
compactness argument on a space of triangles; any limiting/approximation argument. The whole
existence proof is an intermediate value theorem for a scalar function of a scalar angle.

That is a *stronger* claim than it looks, and it is the main reason I distrust it least: a proof
that avoids degree theory cannot be smuggling the conclusion in through a degree computation.
It is also the reason the argument cannot possibly extend to non-convex curves — see §6.

## 4. What broke

### 4.1 (C2) as briefed is FALSE — `refuted`

> **Counterexample.** `K* = { (x,y) : 0 ≤ x ≤ 1, x² ≤ y ≤ √3·x }` and `O = (0,0)`.
> Then `α(O) = π/3` but `O` is **not** a good vertex.

*Verification.* `K*` is the intersection of `{x ≥ 0}`, `{x ≤ 1}`, `{y ≥ x²}` (epigraph of a convex
function) and `{y ≤ √3 x}` (half-plane), hence convex; it is closed and bounded, hence compact;
`(1/2, 1/2)` is an interior point since `1/4 < 1/2 < √3/2`, so `int K* ≠ ∅`. `O = (0,0)` satisfies
`0 ≤ 0 ≤ 0`, so `O ∈ K*`, and `O ∈ ∂K*`.

For `x ∈ (0,1]` the fibre of `K*` is `y/x ∈ [x, √3]`, so the achieved arguments are

  A = ⋃_{x ∈ (0,1]} [ arctan x , π/3 ] = (0, π/3],

an interval whose infimum `0` is **not attained**. Hence `T(O) = {arg ∈ [0, π/3]}` and
`α(O) = π/3`, but `A ≠ [0, π/3]`.

By Proposition R, `O` good would require two directions in `A` differing by exactly `π/3`; but
`A = (0, π/3]` and `θ ∈ A` forces `θ + π/3 > π/3`, outside `A`. Equivalently and even more
concretely: the only boundary points with argument `π/3` lie on the upper edge, and rotating any
of them by `−π/3` about `O` lands on the positive `x`-axis, whereas `K* ∩ {y = 0} = {(0,0)}`.
So no nondegenerate equilateral triangle inscribed in `∂K*` has a vertex at `O`. ∎

**What this kills.** It kills the clause "`α(O) ≥ π/3` ⟹ good" at the single value `α = π/3`,
and it does so for a reason that is invisible from the tangent cone alone: the tangent cone is a
*closure*, and it can contain a direction that `K` itself does not achieve. The correct
hypothesis at `α = π/3` is a statement about `K`, not about `T(O)`. Theorem B(ii) is the repair.

**What this does *not* kill.** (C2) is true verbatim for every convex **polygon** — indeed
whenever `A` is closed — because then both extreme rays of `T(O)` meet `K` in segments. So the
brief's (C2) is a correct theorem about polytopes stated with a hypothesis that is too weak in
the general convex case.

### 4.2 My own first parametrisation was wrong — `refuted`

I first wrote down: "`O` is good iff `r(θ) = r(θ − π/3)` for some `θ`", and on that basis
constructed what looked like a counterexample to (C2) for `α` slightly **greater** than `π/3`
(the thin triangle `O`, `(δ, 0)`, `L·e^{i(π/3+ε)}` with `δ ≪ L`, for which `F = r(θ) − r(θ−π/3)`
is strictly positive throughout). That "counterexample" is bogus: the thin triangle *is* good.
The error is that on an **extreme** ray of the tangent cone the entire radial segment `(0, r(θ)]`
lies in `∂K` (F5), not just its far endpoint, so the correct condition is
`Σ(θ) ∩ Σ(θ−π/3) ≠ ∅` and not `r(θ) = r(θ−π/3)`. In the thin triangle the witness is
`P = r(ε)·e^{i(π/3+ε)}` on the long edge with `Q` the boundary point at argument `ε` — Case B.

I am recording this because it is a textbook instance of `RULES.md` §0: the wrong lemma read
fluently, produced a clean-looking counterexample, and would have been written up as a
refutation of a true statement had I not tried to *build* the triangle explicitly. **The habit
that caught it was constructing an explicit witness rather than trusting the sign of a function.**

### 4.3 The IVT route suggested in the brief — not wrong, but strictly more expensive

The brief proposed running the intermediate value theorem along `J \ {O}` on the function
`P ↦ g(ρ(P)) − 1`, where `g` is the Minkowski gauge of `K` about an interior point (`< 1` inside,
`= 1` on `J`, `> 1` outside). That does work when `α > π/3`, and it has the pleasant feature that
the degenerate root sits exactly at the removed point (`ρ(O) = O ∈ J`, so `h(O) = 0` always).
Two findings about it:

- The "outside" end of the brief's argument is **free and needs no hypothesis at all**. Since
  `inf A = 0` (F3) there are `P ∈ J \ {O}` with `arg(P) ∈ [0, π/3)` arbitrarily close to `0`
  (take the far endpoint of the ray at argument `θₙ ∈ A`, `θₙ → 0`, which is on `J`); then
  `arg(ρ(P)) ∈ [−π/3, 0)` and `ρ(P) ∉ T(O) ⊇ K`. So `h > 0` somewhere, always, for **every**
  `α ∈ (0, π]`. The brief's asymmetric phrasing ("near the far arm it should be outside")
  suggested this needed the hypothesis; it does not.
- The "inside" end is **not** free and is not merely a matter of strictness. For `K` the
  equilateral triangle with `O` a vertex (`α = π/3`), `ρ(P) ∈ int K` holds for **no** `P ∈ J`
  whatever, because `ρ(T(O)) ∩ T(O)` is the single ray `{arg = 0}`, which meets `K` only in `∂K`.
  So the function `h` is `≥ 0` on all of `J \ {O}` there, and the IVT has nothing to work with —
  even though `O` is a perfectly good vertex (the triangle is inscribed in itself). Getting the
  `α = π/3` case right therefore requires the Case A / Case B extreme-ray analysis regardless of
  which IVT one runs.

Additionally the brief's route needs `J \ {O}` to be connected, i.e. `∂K ≅ S¹`, which is a real
(if standard) topological input. The `F(θ)` route in Theorem B needs only the IVT on a real
interval. I kept the cheaper one. This is not a refutation, it is a **dependency reduction**, and
it is the reason the regularity budget in §3 can honestly say "no Jordan curve theorem".

### 4.4 Total turning for (C3) — abandoned, superseded

The brief's (C3) route (exterior angles sum to `2π`; a point with `α < π/3` contributes more than
`2π/3`) is presumably fixable, but making "total turning" precise for a general convex curve
requires either restricting to polygons or introducing the turning measure / monotonicity of the
Gauss map, both of which are heavier than the result. The angle-sum argument of Theorem C proves
more (part (b)) with less. I did not attempt to complete the turning argument and I am not
claiming it fails; I am claiming it is not worth its price here.

## 6. Why this does **not** transfer to the square peg problem

If the argument above proved the square case verbatim it would be wrong, so this section is a
correctness check on the whole attack, not commentary.

**What *does* transfer.** Theorem A transfers with `π/2` in place of `π/3`: if `O,P,R,S` is a
square with `P, S` adjacent to `O` then `∠POS = π/2` and `R − O = (P−O) + (S−O)` also lies in the
convex cone, so `α(O) ≥ π/2`. Theorem C transfers in a weakened form: four boundary points with
`α < π/2` are in convex position (no three are collinear, since a middle point would have
`α = π`), and the interior angles of the resulting convex quadrilateral sum to `2π` while each is
`< π/2` — contradiction. So at most **three** points can have `α < π/2`. Both of these are just
F1 plus Euclidean angle sums, and they are indifferent to which polygon we inscribe.

**What does not transfer, and why.** Theorem B — the existence engine — has no square analogue,
for a reason that is about counting, not about `60°` being pretty:

> Fix `O`. An equilateral triangle with a vertex at `O` is determined by **one** further point
> `P`, and has **one** remaining vertex, namely `ρ(P)`. So "inscribed" is **one** scalar equation
> in **one** unknown, and the intermediate value theorem applies to a one-parameter family.
>
> A square with a corner at `O` is likewise determined by one further (adjacent) corner `P`, but
> it has **two** remaining corners, `S = O + i(P−O)` and `R = P + i(P−O)`. So "inscribed" is
> **two** scalar equations in **one** unknown: an overdetermined system, with no generic
> solutions and no IVT. One is forced to let `O` vary as well — two equations in two unknowns —
> which is a degree/parity problem, and that is precisely why the square peg problem is hard.

Numerically confirmed above: for the equilateral triangle, essentially *no* boundary point is a
corner of an inscribed square. In fact a triangle has exactly three inscribed squares (any square
inscribed in a triangle has two corners on one side, by pigeonhole, and each side determines one),
so at most **twelve** of the uncountably many boundary points are corners of one — against *all*
of them being vertices of an inscribed equilateral triangle. The "all but at most two points"
form of Corollary E is therefore not merely unproved for squares; **its analogue is flatly
false**. That is the sharpest available evidence that the argument is not secretly proving too
much.

**What the method actually proves, in general.** The proof of Theorem B nowhere uses `π/3` except
through the single coincidence "isoceles with apex angle `π/3` ⟹ equilateral". Replacing `π/3` by
any `β ∈ (0, π)` and reading `F_β(θ) = r(θ) − r(θ − β)` gives, by the identical case analysis:

> *(Remark, `sketch`, and I have **not** checked this to destruction — I verified only the
> `β = π/3` case in full detail.)* For any `β ∈ (0,π)`, every `O ∈ ∂K` with `α(O) > β` carries
> `P, Q ∈ ∂K` with `|OP| = |OQ| > 0` and `∠POQ = β`; i.e. `O` is the apex of an inscribed triangle
> similar to any prescribed isoceles triangle. Allowing `G(θ) = λ·r(θ) − r(θ − β)` for `λ > 0`
> plausibly removes the isoceles restriction, giving inscribed triangles of any prescribed shape
> with a prescribed vertex correspondence — which is what makes me suspect the Meyerson overlap
> flagged at the top.

At `β = π/2` this yields "every convex curve carries a right isoceles triangle with its apex at
any point of angle `> π/2`" — true, easy, and **not** the square peg problem. The gap between
that true statement and the square is exactly the fourth corner. A triangle has
`3 = 1 (fixed) + 1 (free) + 1 (determined)` vertices; a square has one too many.

## 7. What is **not** proved here

- **Nothing about non-convex Jordan curves.** F1 (`K ⊆ O + T(O)`) is the load-bearing fact and it
  is false for non-convex curves — there is no "inside" for the curve to be trapped in, `r(θ)` is
  not single-valued, `A` need not be an interval, and the notion "interior angle at `O`" need not
  exist at all. The general Jordan case is a different worker's lane on issue #132
  (`attacks/rotation-continuity/`); **nothing in this file may be reused there** except as
  motivation, and in any case §3 of `RULES.md` forbids building on a `sketch`.
- **No status above `sketch`.** By `RULES.md` §5, `verified:review` can only be granted by an
  agent of a different model family; I cannot grant it to myself and have not. Nothing here
  belongs in `results/` yet.
- **No literature check.** See the provenance warning at the top. The results here are very
  likely known. Establishing that is `cited`-tier, verification-critical work (`RULES.md` §5) and
  is not this lane's.
- **No claim that Theorem B's `α = π/3` boundary case is the *only* subtlety.** It is the only
  one I found. In particular I have not tried to characterise good vertices for `α > π/3` more
  finely than "all of them", nor to count inscribed equilateral triangles at a given vertex.
- **No Lean.** Theorems A and C look like plausible formalisation targets (they are angle-sum
  arguments over a convex-cone containment); Theorem B needs semicontinuity of a radial function
  and would be a real Mathlib exercise. I did not attempt either.
