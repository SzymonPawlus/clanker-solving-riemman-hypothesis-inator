# A compact certificate for the orbit-3 core-free branch

Status: `sketch` pending independent review.

## Definitions and scope

For a nonempty proper vertex set `U`, a dicut is `delta+(U)` when no arc enters `U`.  A
dijoin meets every dicut.  Woodall's nontrivial direction asks for `tau` pairwise disjoint
dijoins when the smallest dicut has size `tau`.

In the sink-regular ACZ model at `tau=3,rho=4`, there are twelve active sources, each of
degree four, and sixteen sinks, each incident with a three-source multiset.  For a source shore
`X`, let `y(X)` count the sink supports contained in `X`.  An M1 base `Q` gives

```text
y(X) <= |X| + |Q intersect X| - 1.
```

Hexadecimal masks use sources `0,1,...,9,A,B`.  This note closes only the issue-#93 orbit-3
core-free branch with lower demands

```text
y(344) >= 4,   y(4c1) >= 4,   y(81c) >= 4.
```

The two ID1009 restrictions and their precise relabellings are regenerated by
[`verify.py`](../../../../experiments/woodalls-rho4/orbit3-core-free/verify.py).  Their union has
63 required bases.

Sanity checks on the underlying definitions: a directed path has singleton dicuts and its whole
arc set is a dijoin; a directed cycle has no dicuts; the two-source diamond has `tau=2` and two
disjoint dijoins.  The executable general checks remain in `experiments/woodalls-dicuts/`.

## The certificate

Put

```text
D1=344, D2=4c1, D3=81c,
C1=818, C2=81c, C3=b3e, C4=cbf.
```

Assign source weights, in order `0,1,...,9,A,B`, by

```text
w=(-1,2,-1,2,2,2,-4,-1,-1,-1,-1,2).
```

Their sum is zero.  For every three-source multiset `S`, direct containment inspection gives

```text
6 sum_i [S subset Di] + sum_{v in S} w(v)
    <= 3 sum_j [S subset Cj].                         (1)
```

This is a small pointwise statement, including multiplicity in the weight sum.  Grouping the
multisupports by their `D`- and `C`-containment signatures gives the following complete table.
In every row the maximum of left-minus-right in (1) is zero.

| D signature | C signature | multisupports | maximum |
|---|---:|---:|---:|
| none | none | 116 | 0 |
| none | 3 | 55 | 0 |
| none | 3,4 | 36 | 0 |
| none | 4 | 99 | 0 |
| 1 | none | 9 | 0 |
| 1 | 3 | 9 | 0 |
| 1,2 | none | 1 | 0 |
| 1,3 | 2,3,4 | 1 | 0 |
| 2 | none | 9 | 0 |
| 2 | 4 | 10 | 0 |
| 3 | 1,2,3,4 | 10 | 0 |
| 3 | 2,3,4 | 9 | 0 |

The counts sum to all 364 unordered three-source multisets.  The checker regenerates this
classification and inequality rather than trusting the table.

Sum (1) over the sixteen sinks.  Every source has degree four, so the weight term becomes
`4 sum_v w(v)=0`.  Hence

```text
2(y(D1)+y(D2)+y(D3)) <= y(C1)+y(C2)+y(C3)+y(C4).     (2)
```

The required bases with hexadecimal masks `107,0f0,4d0,350` (element words
`0128,4567,467A,4689`) give, respectively,

```text
y(818) <= 2,  y(81c) <= 4,  y(b3e) <= 8,  y(cbf) <= 9.
```

Thus the three lower demands make the left side of (2) at least `2(4+4+4)=24`, while the
four base caps make its right side at most `2+4+8+9=23`, a contradiction.

The argument is rational and does not need integrality or the earlier split into `y({1,5})=0`
and `y({1,5})=1`.  It therefore closes both branches simultaneously.

## Filters and limits

- **Schrijver filter: passed.** The degree-four/sink-indegree-three ACZ structure and M1 base
  rows are specifically unweighted.  No weighted Edmonds--Giles statement is inferred.
- **Lucchesi--Younger filter: passed.** No dicut/dijoin role reversal is used.
- **Easy-direction filter: passed.** This excludes an obstruction to the constructive ACZ
  partition route; it does not restate the trivial packing upper bound.

The earlier claim that the residual four sinks all have split `1U+2K` was false: `y(K)=1` also
permits one `0U+3K` and one `2U+1K` support.  That split argument remains refuted.  The corrected
200-support integer model was valid but unnecessarily weak: inequality (2) gives a short rational
certificate.  Closing this branch does not close higher covers in the other relative orbits, much
less prove that the full bad-complement family is intersecting.
