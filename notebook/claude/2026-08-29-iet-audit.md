## Findings

Nothing in the directory is mathematically false as a *statement*. All four findings are wrong
explanations attached to right conclusions, plus one arithmetic slip.

**E1 — `r` is continuous on all of `[0,α]`, not merely usc at the endpoints.** The README's note
under F6 says `r` "genuinely can be discontinuous there (see §4.1)" and that "that gap is exactly
where (C2) fails". Both false. usc at `0` gives `limsup r ≤ r(0)` outright; if `r(0) = 0` that
forces `r → 0`, and if `r(0) > 0` the triangle `conv{0, r(0)e^{i0}, r(ψ₂)e^{iψ₂}} ⊆ K` has a
continuous positive radial function bounding `r` below, giving `liminf ≥ r(0)`. So `r` is
continuous. This is the one I am most pleased with, because §8 of the README nominates this exact
step as its **single least-certain step**, marked `[ATTACK HERE]` — and it is more robust than the
author thinks. The real mechanism of `K*` is `Σ(0) = ∅` (direction 0 unachieved), which the README
states correctly *everywhere else*; only the F6 note misdiagnoses it. Nothing breaks: Theorem B
uses only usc, which is true.

**E2 — Proposition D's witness comes from Case A, not Case C.** `r(0) = 1 ≥ r(π/3) = 1/2` on the
30–30–120 triangle, so Case A fires and Case C is by definition its negation. `θ₀ = π/2` *is* a
root of `F`, but the proof's case analysis never reaches it. Case A's actual witness is
`(0,0), (1/2,0), (1/4,√3/4)` with side `1/2`, which I verified exactly. Matters because
Proposition D is offered as an illustration of how Theorem B runs, and a reader checking it
against the case analysis cannot make it come out.

**E3 — `(2−√3)/2 ≈ 0.267949` is wrong**; `(2−√3)/2 = 0.1339746` and the decimal is `2 − √3`. From
my exact enumeration the base square's corners are at `x = 2−√3` and `x = √3−1`. Cosmetic (§5 is
`numerical`), but it is a closed form someone would copy.

**E4 — the `depends-on` list overstates "proved inline as F1–F6".** F2 uses the supporting
hyperplane theorem, F4 uses `[w,y) ⊆ int K`, Corollary E uses `∂K` uncountable — none proved. All
textbook, none topological, so the headline "no Jordan curve theorem" survives; but "proved
inline" is exactly the sentence a later reader trusts without rechecking.

## Verdicts on the five briefed items

1. `K*` — **agreed**, reconstructed completely and exactly: convex, compact, `int ≠ ∅`, `O ∈ ∂K*`,
   `A = (0,π/3]` with direction 0 provably unachieved (`y ≥ x²` and `y = 0` force `x = 0`), and the
   exclusion is **global**: it uses only `P, Q ∈ K*∖{O}`, which holds for every point of `J`, so
   there is no "both other vertices near `O`" escape. The refutation of (C2) stands.
2. Theorem B — **agreed**, including B(ii), which I attacked hardest: with `α = π/3` the only
   admissible angle pair in Proposition R is `(π/3, 0)`, so the `iff` is forced. The IVT-on-an-
   angle-interval claim is honest — no JCT, no degree, no rectifiability, no limit of triangles.
   The semicontinuity directions point the right way. Degeneracy is excluded because every case
   puts its angle in the *open* `(0,α)` where `r > 0`.
3. Theorem C — **agreed**, both halves and the strengthened (b). Non-collinearity, angle bound,
   four-point reflection exclusion, and `K = ⋂(Oᵢ + T(Oᵢ)) = T` all reconstructed.
4. Proposition D — **agreed on the arithmetic** (exact sympy: sides all `√3/3`, `P` and `Q` on
   `BC` at parameters `2/3` and `1/3`, cross products exactly zero), **disagreed on E2**.
5. Square non-transfer — **agreed**, and this is where I most wanted to find a break. In radial
   coordinates the square is `r(θ) = r(θ+π/2)` **and** `√2 r(θ) = r(θ+π/4)` — two equations, one
   unknown — against the triangle's single `r(θ) = r(θ−π/3)`. I also enumerated inscribed squares
   in the equilateral triangle **completely and exactly** over `ℚ(√3)` (81 edge-assignments × 2
   orientations, `4×4` exact linear solves): exactly **3** squares, side² `= 21−12√3`, exactly
   **12** distinct corner points. So the "all but two points" analogue really is flatly false for
   squares. K5 does not fire.
