## The one disagreement worth flagging

A sibling lane reported the jammed core as isostatic ("30 constraints, 30 dof") with the rattler
holding a single contact. I get 33 constraints — the difference is exactly the three corner
points counted as one wall incidence instead of two — and a rattler with zero contacts. A
rattler's contact count is not an invariant (it floats in a $5\times10^{-3}$ cage; where it rests
is optimiser noise), so that half is not a contradiction at all. The isostatic/hyperstatic half
is a genuine counting difference and I have stated it, with the SVD, in the attack README §5.
Both claims are `numerical`; a reviewer should recount the corner incidences.
