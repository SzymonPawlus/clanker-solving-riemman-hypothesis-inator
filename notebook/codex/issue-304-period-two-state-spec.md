# Exact residual-state exclusion of covers without period two

Status: `sketch`; all fourteen author graphs completed, independent replay
pending. This is a new attack. It does not use the lost earlier
state graphs or their rejected negative-weight certificates.

## Sanity filters and row definition

The target is fourteen moving velocities, fifteen total runners, threshold
`1/15`. All rows concern the same lower endpoint `(15j+1)/(15M)` of the
maximal speed `M`. For a smaller positive speed, reduce the pair to
`h=M/gcd(M,w)`, `a=w/gcd(M,w)`. Signs and repeated absolute speeds do not
change the conditions. Only common integer scaling is used. The bad set is

```text
B(h,a) = {j mod h : min(s,15h-s)<h},
s = a(15j+1) mod 15h, 1<=a<h, gcd(a,h)=1.
```

The strict inequality is essential: an endpoint at distance exactly `1/15`
survives. For example, at `t=1/15` speed one is allowed. The fixture
`B(2,1)={0}` uses the same strict convention.

An equivalent exact construction writes `e=a+15k` with `-h<e<h`, and maps
each such integer `k` to `a^(-1)k mod h`. A checker may instead evaluate the
displayed modular inequality directly; it must not read or translate the
author generator when supplying independent review.

## Complete branching argument

Fix a minimum allowed row period `p`. A state `(r,L,R)` means that `R` is
the nonempty set of still uncovered indices modulo `L`, and at most `r`
further rows of periods at least `p` may cover it. No assumptions are made
about which earlier rows led to the state. This enlarges the search family
and makes identical residual states safe to identify.

For an additional row `(h,a)`, put `d=gcd(h,L)`, `n=h/d`. Over each residue
`j mod L`, the lifted row occupies at most `ceil(2n/15)` of its `n` copies
modulo `lcm(L,h)=Ln`. To see this, the admissible centered representatives
`e` for that fiber form one class modulo `15d` inside the open interval
`(-h,h)`, of length `2h=2dn`.

If `r` rows cover the residual set, at least one has at least `|R|n/r`
hits after lifting. Therefore some next row has

```text
r ceil(2n/15) >= n.
```

For `r<=6`, this implies `n<=14r/(15-2r)`, since
`ceil(2n/15)<=(2n+14)/15`. The exact admissible sets are

```text
E6={1,2,3,4,5,6,8,9,10,11,12,16,17,18,23,24},
E5={1,2,3,4,5,8,9,10},
E4={1,2,3,4,8}, E3={1,2,3}, E2={1,2}, E1={1}.
```

All possible rows are thus generated by choosing `d|L`, `n in E_r` with
`gcd(n,L/d)=1`, setting `h=dn>=p`, and taking every `1<=a<h` coprime to
`h`. For each, lift `R` to `Ln`, count its intersection with `B(h,a)`
exactly, and keep the child precisely when `r*hits>=n*|R|`. Remove those
hits and decrement `r`.

Different numerators with the same conditional hit counts need not have
the same actual lifted child. They must all be generated. It is safe to
retain only one representative per equal resulting residual state.

After removing a row, reduce the residual indicator to its true period:
choose the smallest divisor `D` of `Ln` for which the residual equals the
full lift of its image modulo `D`. Equivalently, the image cardinality times
`Ln/D` must equal the full residual cardinality. An empty residual means a
cover was found; its convenient period is one. This compression does not
change any subsequent row coverage or the complete branching argument.

## Graph certificate format and independent obligations

Each `no-period-two-pN.json` records one fixed lower period bound `p=N`.
Its roots are all distinct complements of `B(p,a)` in `Z/pZ`, with six
rows remaining. Every possible cover with smallest period `p` has such a
root. There is no unproved symmetry quotient of the base numerators.

A node records its identifier, `remaining`, `period`, and sorted `residual`.
A `branch` lists one `(h,a,child)` representative for each distinct
qualifying residual child defined above. A leaf with an empty child list
is excluded because any covering completion would provide a qualifying
next row. A `nonempty` node at zero rows is likewise excluded.
An `open` node or `cover-found` node prevents an exclusion conclusion.

For an independent replay, reconstruct all roots from the modular row
definition, check that each node has a valid residual period, regenerate
every qualifying child, and compare the entire set of target states with
the recorded children. Check the representative row actually gives its
child. Check that every edge decrements the remaining-row count and that
no root can reach an open state or an empty residual. Unreferenced nodes
do not weaken root coverage, but should be reported. Node identifiers are
only references, never mathematical evidence.

The author's generator optionally supports rational dual leaves. The
current resumed campaign deliberately uses `--no-dual`; a checker of these
files should reject unexpected `dual` nodes. This avoids any dependency
on an optimization library or rounding convention in the certificate.

## Scope

Completed files for `p=3,...,16`, if all replay successfully, exclude a
seven-row cover without period two whose minimum row period is at most
sixteen. Combining this with the separately stated and checked minimum-
period-sixteen reduction would give necessity of period two. That reduction
must be reconstructed or reviewed separately; this graph specification
does not assume it is already a verified claim.

The existing forty-four universal phase certificates and their manifest
remain frozen. This document neither promotes them nor claims the full
Lonely Runner conjecture.
